## SCR-001. 스플래시

```
┌─────────────────────────┐
│                         │
│                         │
│                         │
│        [앱 로고]         │
│       댕댕케어           │
│   강아지와 더 안심하게    │
│                         │
│                         │
│                         │
└─────────────────────────┘
```

**구성 요소**
- 앱 로고 (중앙 상단 1/3 지점)
- 앱 이름
- 서비스 슬로건
- 배경: 메인 컬러 또는 화이트

**동작**
- 1.5초 후 자동으로 다음 화면으로 이동
- 최초 실행: 온보딩으로
- 재실행: 홈으로

## 주요 인터랙션 정의

| 인터랙션 | 동작 |
|---------|------|
| 음식 검색 결과 탭 | 결과 화면으로 푸시 |
| 병원 카드 탭 | 상세 화면으로 푸시 |
| 병원 전화 버튼 탭 | 전화 앱 실행 |
| 길찾기 버튼 탭 | 카카오맵/네이버맵 딥링크 |
| 기록 카드 탭 | 상세/수정 화면으로 |
| 증상 체크 뒤로가기 | 이전 질문으로 (스택 팝) |
| 홈 퀵메뉴 탭 | 해당 탭으로 즉시 이동 |

## 광고 영역 레이아웃 규칙

1. 배너 광고: 탭바 바로 위 고정, 높이 50pt
2. 인터스티셜: 화면 전환 시 전체 화면, 닫기 버튼 5초 후 활성화
3. 네이티브 광고: 목록 아이템과 동일한 카드 스타일, `[광고]` 라벨 표시
4. 긴급 상황 화면(즉시 병원)에서는 광고 미노출
