# 서비스 기획서

**서비스명:** 댕댕케어 (DaengDaeng Care)
**버전:** v1.0
**플랫폼:** iOS
**작성일:** 2026-06-12

---

## 1. 서비스 개요

### 한 줄 정의
반려견 보호자를 위한 건강 관리 올인원 앱 — 음식 안전, 사료 성분, 증상 체크, 병원 찾기, 건강 기록을 하나에서.

### 배경
- 국내 반려동물 가구 약 1,500만 (4가구 중 1가구)
- 반려견 보호자의 가장 큰 불안: "이거 먹어도 돼?", "병원 가야 하나?", "접종 언제였지?"
- 기존 앱들은 기능이 분산되어 있어 여러 앱을 오가야 하는 불편함 존재
- 하나의 앱에서 일상적인 반려견 건강 관련 궁금증을 해결하는 서비스 부재

### 핵심 가치
> "강아지와 함께하는 매일, 더 안심하게"

---

## 2. 타겟 사용자

### 주요 타겟
- 반려견을 키우는 20~40대 (특히 1인 가구, 신혼부부)
- 반려견을 처음 키우기 시작한 초보 보호자
- 반려견 건강에 예민하고 정보를 직접 찾아보는 보호자

### 사용자 페르소나

**페르소나 A — 초보 보호자 김지수 (28세)**
- 3개월 전 말티즈 입양
- 뭘 먹여도 되는지 몰라서 매번 검색
- 접종 날짜 놓친 경험 있음
- 밤에 강아지가 이상해 보이면 응급 병원 어딘지 몰라서 패닉

**페르소나 B — 베테랑 보호자 이민준 (35세)**
- 골든리트리버 5년째 양육
- 사료 성분에 민감하게 관리
- 건강 기록을 노트에 직접 쓰고 있음
- 더 체계적인 기록 도구를 원함

## 3. 핵심 기능 요약

| 기능 | 설명 | 사용 빈도 |
|------|------|----------|
| 음식 판별기 | 먹어도 되는지 즉시 확인 | 매일 |
| 사료 분석기 | 바코드 스캔으로 성분 위험도 분석 | 구매 시 |
| 증상 체크 | 증상 입력 → 병원 필요 여부 판단 | 수시 |
| 병원 찾기 | 현재 위치 기반 24시간 동물병원 | 긴급 시 |
| 건강 기록 | 예방접종, 체중, 병원 방문 기록 | 주 1회 |

## 4. 수익 모델

### AdMob 광고 (메인 수익)
- **배너 광고:** 각 결과 화면 하단 고정
- **인터스티셜 광고:** 증상 체크 결과 진입 직전 (가장 집중도 높은 순간)
- **네이티브 광고:** 병원 목록 중간 삽입

### 수익 구조 원칙
- 긴급한 상황(병원 찾기, 증상 체크 진행 중)에는 광고 미노출
- 정보 확인 완료 후 자연스러운 맥락에서만 노출
- UX를 해치지 않는 광고 빈도 유지

---

## 5. UX 원칙

1. **즉각성** — 3초 안에 원하는 정보에 도달할 수 있어야 함
2. **신뢰감** — 건강 관련 앱이므로 정보의 출처와 근거를 명시
3. **안심감** — 색상, 톤, 언어 모두 따뜻하고 안정적으로
4. **단순함** — 기능이 많아도 홈은 심플하게, 깊이는 탭 안으로

## 6. 디자인 방향

### 톤 앤 무드
- 따뜻하고 신뢰감 있는 느낌
- 과하지 않은 귀여움 (반려동물 앱이지만 유치하지 않게)
- 의료/건강 앱의 신뢰성 + 반려동물 앱의 친근함의 균형

### 컬러 방향
- 메인: 따뜻한 계열 (오렌지/앰버 계열 또는 그린 계열 검토)
- 보조: 밝은 뉴트럴
- 경고: 레드/옐로우/그린 3단계 명확하게 구분
- 배경: 화이트 또는 아주 연한 크림

### 타이포그래피
- 한국어 가독성 최우선
- 결과 화면의 핵심 정보는 크고 굵게
- 설명 텍스트는 가볍고 읽기 쉽게

## 7. 기술 제약사항 (디자인 반영 필요)

- **플랫폼:** iOS 전용 (iPhone 기준, 다크모드 대응)
- **컴포넌트 패턴:** Compound Component Pattern 적용
  - 각 화면의 UI 요소가 조합 가능한 구조
  - 예: `<FoodCard>`, `<FoodCard.Badge>`, `<FoodCard.Description>`
- **광고 영역:** 배너 높이 50~60pt 고정 영역 레이아웃에 반영 필요
- **Safe Area:** iPhone 노치/다이나믹 아일랜드 대응
