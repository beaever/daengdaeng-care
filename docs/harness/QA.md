# QA — 댕댕케어 하네스 가이드

## 역할 범위
QA는 **품질 게이트**를 소유한다. 기능이 명세대로 동작하는지, 엣지케이스를 처리하는지 검증한다.

---

## 테스트 전략

### 단위 테스트 (vitest — `packages/*`)
- 범위: `packages/constants` 데이터 로직(음식 DB, 증상 트리), 유틸 함수
- 음식 검색 함수: 부분일치, 별칭, 한글/영문 혼합 케이스

### 컴포넌트/로직 테스트 (jest-expo — `apps/mobile`)
- 범위: `components/ui`, `components/compound`, `lib`(SQLite 저장/조회 등)
- Storybook/Chromatic은 `packages/ui`(동결, 웹 전용)에만 존재 — 앱 화면과 무관, 앱 QA 범위 아님

### E2E 테스트 — 없음
- Detox 등 미도입. 실기기 수동 QA(아래 체크리스트)가 E2E를 대체한다

---

## 실기기 TestFlight QA 체크리스트

### 첫 실행 / 데이터 유지
- [ ] 온보딩 → 프로필(이름·품종·생년월일·성별·중성화·사진) 저장 완료된다
- [ ] 앱을 완전히 재시작해도 저장한 프로필이 그대로 보인다
- [ ] 앱을 강제 종료(스와이프 종료) 후 다시 열어도 프로필·건강 기록이 유지된다

### 권한 흐름
- [ ] 위치 권한 거부 시 병원 찾기가 지역 검색으로 대체되고 멈추지 않는다
- [ ] 위치 권한 허용 시 현재 위치 기준 거리순 병원 목록이 뜬다
- [ ] 사진 권한 거부/허용 모두에서 프로필 사진 설정 흐름이 멈추지 않는다

### 응급 플로우 / 면책 고지
- [ ] 응급 수준 증상 선택 시 "바로 병원으로" 버튼으로 병원 찾기 화면까지 바로 이동한다
- [ ] 증상 체크 결과 화면에 수의사 면책 고지 문구가 항상 보인다
- [ ] 응급 화면 어디에도 광고(배너/인터스티셜)가 없다

### 네트워크
- [ ] 비행기 모드에서 홈/음식 판별/증상 체크/병원 찾기/건강 기록/설정 탭 전환이 멈추거나 크래시 없이 동작한다

### 레이아웃 / 접근성
- [ ] iPhone SE(375pt)에서 모든 화면 레이아웃이 깨지지 않는다
- [ ] iPhone Pro Max에서 모든 화면 레이아웃이 깨지지 않는다
- [ ] 설정 > 손쉬운 사용 > 더 큰 텍스트 켠 상태에서 텍스트가 잘리거나 겹치지 않는다
- [ ] VoiceOver로 주요 버튼(퀵메뉴, 응급 CTA, 하단 탭)이 올바른 라벨로 읽힌다

### 앱 기본
- [ ] 스플래시 화면이 정상 표시된다
- [ ] 홈 화면 아이콘이 정상 표시된다

## 치명 버그 정의
크래시, 데이터 손실(프로필/건강 기록 소실), 면책 고지 누락, 응급 플로우(병원 이동) 막힘, 심사 거절 사유(권한 설명 누락 등)에 해당하면 치명 버그로 분류하고 머지/제출을 막는다.
