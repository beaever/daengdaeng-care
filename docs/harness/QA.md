# QA — 댕댕케어 하네스 가이드

## 역할 범위
QA는 **품질 게이트**를 소유한다. 기능이 명세대로 동작하는지, 엣지케이스를 처리하는지 검증한다.

---

## 테스트 전략

### 단위 테스트 (vitest)
- 범위: `packages/constants` 데이터 로직, 유틸 함수
- 커버리지 목표: **branches 80%** 이상
- 음식 검색 함수: 부분일치, 별칭, 한글/영문 혼합 케이스

### 컴포넌트 테스트 (Storybook + Chromatic)
- 모든 Atom/Molecule/Compound에 Story 필수
- 라이트/다크 각각 스냅샷
- Chromatic PR 통과 없이 머지 불가

### E2E 테스트 (Detox — v1.1 예정)
- 핵심 플로우만: 음식 검색 → 결과, 증상 체크 → 결과, 병원 찾기

---

## 필수 테스트 케이스

### 응급 플로우
- [ ] 응급 증상 선택 시 인터스티셜 광고가 표시되지 않는다
- [ ] 응급 결과 화면 하단에 배너 광고가 없다
- [ ] 응급 화면에서 "바로 병원으로" 버튼이 즉시 활성화된다

### 음식 판별
- [ ] 검색어 "포도" → danger 결과
- [ ] 검색어 "grape" → danger 결과 (영문 별칭)
- [ ] 검색어 "청포도" → 포도 결과 (부분 일치)
- [ ] 검색어 "XXX 알 수 없는 음식" → "확인되지 않은 음식" 안내

### 다크모드
- [ ] 모든 텍스트가 하드코딩 hex가 아닌 테마 토큰을 사용한다
- [ ] 배지/카드 배경이 다크모드에서 정상 표시된다

### 레이아웃
- [ ] iPhone SE (375pt) 에서 레이아웃이 깨지지 않는다
- [ ] 배너 광고 로드 전/후 레이아웃 점프가 없다 (52px 사전 예약)
- [ ] 탭바가 iPhone 홈 인디케이터와 겹치지 않는다
