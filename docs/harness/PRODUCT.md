# Product — 댕댕케어 하네스 가이드

## 역할 범위
Product는 **무엇을 만들 것인가**를 정의한다. 기능 범위, 우선순위, 성공 지표를 소유한다.

---

## 핵심 원칙

1. **긴급 플로우는 절대 건드리지 않는다** — 응급 증상 화면에 광고·실험·팝업 삽입 금지
2. **v1.0 범위 사수** — 사용자 요청이어도 다음 버전 기능을 이번 릴리스에 슬쩍 넣지 않는다
3. **3초 룰** — 사용자가 원하는 정보에 3탭(클릭) 이내에 도달해야 한다
4. **데이터 근거** — 스펙 변경 시 반드시 근거(사용자 피드백, 데이터)를 PR 설명에 명시

## 수익화 규칙 (Product 관리)

```
배너 광고    → 결과 화면 하단 고정 52px
인터스티셜  → 증상 결과 진입 전 (비응급만), 5초 후 스킵
네이티브 광고 → 병원 목록 3번째 항목
🚨 금지: 응급(emergency) 플로우 어디에도 광고 없음
```
