# 03 · 화면 명세 (16 Screens)

> 원본 구현: `reference/daeng/app/screens.jsx`. 직접 눌러보려면 `reference/Prototype.html`을 브라우저로 열고 우상단 "화면" 드롭다운으로 점프.
> 화면 = 컴파운드 컴포넌트의 조합. 아래는 레이아웃·동작·필요 상태.

공통 셸 (`app/shell.jsx`):
- **Header**: 좌측 뒤로(있을 때) · 중앙 타이틀(iOS, 17/800) 또는 좌측 큰 타이틀(Android, 21/800) · 우측 액션. 상단 safe-area inset 포함
- **TabBar**: 5탭(홈/음식/증상/병원/기록), 아이콘+라벨(10.5/700), 활성=`brand-text`. **하단 safe-area 여유 inset** (iOS 34 / Android 12) — 디바이스 최하단에 붙지 않게
- **AppScreen**: header + 스크롤 본문 + (광고) + (탭바). 본문 좌우 패딩 20px

---

## SCR-001 · 스플래시
- **목적**: 앱 실행 진입
- **레이아웃**: 풀스크린 브랜드 그라데이션(`brand-400→600`), 중앙 로고 마크(흰색, pop 애니메이션 `ease-spring`) + "댕댕케어"(30/800/흰색) + 태그라인 "강아지와 함께하는 매일, 더 안심하게"
- **동작**: 1.7초 후 온보딩으로 자동 전환(reset)

## SCR-002 · 온보딩 (3슬라이드)
- **목적**: 핵심 가치 소개 (최초 1회)
- **레이아웃**: 상단 "건너뛰기"(우측, safe-area 아래) · 중앙 일러스트(200 라운드 박스 + 이모지) · 타이틀(24/800, 2줄) · 설명(15/text-2) · 하단 도트 인디케이터(활성=22px 늘어난 브랜드 pill) · "다음/시작하기" 버튼
- **슬라이드**: ①🥦 음식 판별 ②🩺 증상 체크 ③📋 건강 기록
- **동작**: 다음→인덱스+1, 마지막→프로필 등록. 건너뛰기/시작하기→프로필
- **상태**: `onbIdx`

## SCR-003 · 프로필 등록
- **목적**: 반려견 정보 입력 (최초 1회)
- **레이아웃**: 사진 추가 원형(점선 보더 96, 카메라 아이콘) · 이름(필수) · 품종(검색 인풋) · 생년월일(날짜 선택 행) · 성별(PillGroup 남아/여아) · 중성화(PillGroup 했어요/안했어요/몰라요) · "시작하기"
- **동작**: 시작하기→홈(reset). 탭바 없음
- **상태**: `pfName, pfBreed, pfSex, pfNeu`

## SCR-004 · 홈 (탭1)
- **목적**: 허브
- **레이아웃**: 커스텀 헤더("안녕하세요 👋" + "{이름} 보호자님" 22/800, 우측 설정·알림 아이콘) · **PetProfileCard** · "바로가기" **QuickMenu 2×2**(음식판별/사료분석/증상체크/병원찾기) · "건강 요약" **HealthSummaryCard**
- **동작**: 각 QuickMenu→해당 탭/스택, 프로필카드·설정아이콘→설정

## SCR-005 · 음식 검색 (음식 탭)
- **목적**: 음식 이름 검색
- **레이아웃**: 큰 검색바(50px, `surface-2`) · 검색어 없을 때: "많이 찾는 음식" 브랜드 칩들 + "최근 검색" 리스트(삭제 ✕) · 검색어 있을 때: 자동완성 매칭 행 또는 EmptyState("검색 결과가 없어요")
- **동작**: 칩/행 탭→음식 결과(push), 검색어 seed
- **상태**: `foodQuery`, 결과로 넘길 `foodResult`(음식명)
- **데이터**: `data.js` foods (포도·초콜릿·양파=위험, 치즈·수박=주의, 당근·닭고기·사과=안전)

## SCR-006 · 음식 결과 (음식 탭)
- **목적**: 안전도 판정 표시
- **레이아웃**: **FoodResult** 컴파운드 (02 문서). 하단 **AdBanner**
- **동작**: 뒤로→검색
- **상태**: `foodResult`

## SCR-007 · 사료 스캔 (음식 탭)
- **목적**: 바코드 스캔 진입
- **레이아웃**: 카메라 뷰(어두운 그라데이션) + 스캔 프레임(모서리 4개 + **레이저 라인 상하 애니메이션**) + 힌트 텍스트 · "또는" 구분선 · "제품명으로 검색" 보조 버튼
- **동작**: 카메라/검색 탭(데모)→사료 분석 결과

## SCR-008 · 사료 분석 결과 (음식 탭)
- **목적**: 성분 등급·주의 원료
- **레이아웃**: **FoodAnalysisResult** 컴파운드 (제품 헤더 + 등급 + 원료 TOP5 + 주의 원료). 하단 AdBanner("맞춤 사료 추천")
- **데이터**: `data.js` product (로얄캐닌 미니 어덜트, 등급 B)

## SCR-009 · 증상 카테고리 (증상 탭)
- **목적**: 증상 부위 선택
- **레이아웃**: 2열 그리드 카드 6개(이모지+라벨+서브: 소화기🤢/호흡기😮‍💨/움직임🦴/눈귀코👁️/피부🩹/행동😴) · 하단 **응급 증상 배너**(danger soft 배경, 🚨 "발작·의식없음·호흡곤란")
- **동작**: 카테고리→증상 질문(인덱스 0 초기화), 응급 배너→증상 결과(emergency 직행)

## SCR-010 · 증상 질문 (증상 탭)
- **목적**: 단계별 의사결정
- **레이아웃**: **SymptomChecker** (진행바 + 질문 + 라디오 보기)
- **동작**: 보기 선택 시 분기 — `verdict` 있으면 결과(emergency는 직행/그 외는 전면광고 경유), `next` 있으면 다음 질문. 뒤로→이전 질문 또는 카테고리
- **상태**: `symptomIdx, symptomVerdict`
- **데이터**: `data.js` symptomQuestions (구토 시나리오 트리)

## (인터스티셜) · 전면 광고
- **목적**: 비응급 결과 직전 전면 광고
- **레이아웃**: 스크림 위 카드(광고 아트 + 카피 + CTA). 5초 카운트다운 후 닫기(✕) 노출 → "닫고 결과 보기"
- **동작**: 닫기→증상 결과(replace). **emergency는 이 화면을 거치지 않음**

## SCR-011 · 증상 결과 (증상 탭)
- **목적**: 병원 필요 여부 + 행동 지침
- **레이아웃**: **SymptomResult** 컴파운드. emergency가 아니면 하단 AdBanner
- **동작**: 병원 찾기 버튼(emergency/today)→병원 탭
- **상태**: `symptomVerdict` (emergency/today/watch)

## SCR-012 · 병원 목록 (병원 탭)
- **목적**: 근처 병원 탐색
- **레이아웃**: 툴바(뷰토글 지도/목록 + 반경 칩) · 지도 영역 · "주변 동물병원 N곳" · **HospitalCard** 리스트, **3번째에 NativeAd**
- **동작**: 카드→병원 상세
- **상태**: `hospView`, 선택 시 `selectedHospital`
- **데이터**: `data.js` hospitals (4곳, 강남응급의료센터=24시)

## SCR-013 · 병원 상세 (병원 탭)
- **목적**: 병원 정보 + 연결
- **레이아웃**: 지도(170) · 이름(h1) + StatusBadge · 정보 행(주소📍/진료시간/전화) · 하단 "전화" + "길찾기" 버튼
- **동작**: 전화/길찾기(연동 자리)

## SCR-014 · 건강 기록 (기록 탭)
- **목적**: 기록 타임라인
- **레이아웃**: 큰 타이틀 헤더(우측 + 아이콘) · **HealthRecord**(펫헤더 + 카테고리 탭 + 타임라인) · **우하단 FAB(+ 아이콘)** · 하단 AdBanner
- **동작**: FAB/헤더+→기록 추가
- **상태**: `recTab` (all/vaccine/weight/vet)
- **데이터**: `data.js` records

## SCR-015 · 기록 추가 (모달/시트)
- **목적**: 기록 입력
- **레이아웃**: 기록 종류 선택(3칩: 💉예방접종/⚖️체중/🏥병원방문) → **종류별 동적 폼**:
  - 접종: 백신종류·접종일·다음예정일(자동)·메모
  - 체중: 날짜·체중(kg)·메모
  - 병원: 방문일·병원이름·방문사유·메모
- · "저장하기"
- **동작**: 저장→뒤로
- **상태**: `addType`

## SCR-016 · 설정
- **목적**: 프로필·앱 설정
- **레이아웃**: "반려견 프로필"(펫 행) · "앱 설정"(알림/단위) · "약관"(개인정보·이용약관) · 버전 "v1.0.0"
- **동작**: 뒤로→홈

---

## 화면 전이 요약
```
스플래시 →(1.7s) 온보딩 →(완료) 프로필 →(완료) 홈[탭]
홈 ─QuickMenu→ 음식검색→음식결과 / 스캔→분석결과 / 증상카테고리→질문→(광고)→결과 / 병원목록→상세
탭바: 홈 · 음식 · 증상 · 병원 · 기록
기록 ─FAB→ 기록추가(시트)
홈 헤더 ─→ 설정
증상결과(emergency/today) ─→ 병원목록
```
