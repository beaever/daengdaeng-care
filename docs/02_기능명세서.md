## F001. 먹어도 되는 음식 판별기

### 개요
보호자가 강아지에게 주려는 음식의 안전 여부를 즉시 확인하는 기능

### 입력
| 입력 방식 | 설명 |
|----------|------|
| 텍스트 검색 | 음식 이름 한글/영문 입력 |

### 처리
- 로컬 DB (JSON)에서 검색어 매칭
- 부분 일치 검색 지원 (예: "포도" → "청포도", "건포도" 포함)
- 검색 결과 없을 시 "확인되지 않은 음식" 안내

### 출력 — 결과 3단계

| 단계 | 표시 | 색상 | 의미 |
|------|------|------|------|
| 안전 | ✅ 먹어도 괜찮아요 | 그린 | 일반적으로 안전 |
| 주의 | ⚠️ 소량만 괜찮아요 | 옐로우 | 과다 섭취 시 위험 |
| 위험 | 🚨 절대 주지 마세요 | 레드 | 독성, 즉시 위험 |

### 결과 화면 포함 정보
- 안전 단계 배지
- 이유 설명 (1~2문장)
- 위험 성분명 (해당 시)
- 섭취 시 증상 (위험/주의 단계만)
- 관련 음식 추가 표시 (예: 포도 → 건포도, 포도주스도 위험)

### 주요 데이터 (위험 식품 예시)
```
위험: 포도/건포도, 초콜릿, 양파/마늘, 자일리톨, 마카다미아,
      아보카도, 알코올, 카페인, 날 반죽(이스트), 소금 과다,
      자두/복숭아 씨, 생 계란 흰자

주의: 우유, 치즈, 땅콩버터(자일리톨 없는 것), 수박(씨 제거),
      블루베리, 당근, 오이

안전: 닭고기(익힌 것), 소고기(익힌 것), 쌀밥, 고구마,
      브로콜리, 사과(씨 제거)
```

### 광고
- 결과 화면 하단 배너 (50pt 고정)

## F002. 사료 성분 분석기

### 개요
사료 바코드를 스캔하여 성분의 위험도 및 품질을 분석하는 기능

### 입력
| 입력 방식 | 설명 |
|----------|------|
| 바코드 스캔 | 카메라로 사료 포장 바코드 인식 |
| 수동 검색 | 제품명 직접 입력 (바코드 인식 실패 시) |

### 처리
1. expo-barcode-scanner로 바코드 값 추출
2. Open Pet Food Facts API 호출 (`https://world.openpetfoodfacts.org/api/v0/product/{barcode}.json`)
3. 성분 리스트 파싱
4. 위험 성분 매칭 (자체 위험 성분 DB와 대조)

### 출력

**제품 기본 정보**
- 제품명, 브랜드, 사진 (API 제공 시)
- 전체 등급 (A~D)

**성분 분석 결과**
| 분류 | 내용 |
|------|------|
| 주요 원료 | 첫 5개 성분 강조 표시 |
| 위험 성분 | 레드 태그로 강조 |
| 주의 성분 | 옐로우 태그 |
| 양호 성분 | 그린 태그 |

**주요 위험/주의 성분**
```
위험: BHA, BHT, 에톡시퀸, 프로필렌 글리콜, 인공색소(Red 40 등)
주의: 옥수수 시럽, 부산물(by-product), 밀글루텐, 인공향료
양호: 진짜 고기(Chicken, Beef), 고구마, 완두콩
```

### 예외 처리
- 바코드 인식 실패 → 수동 검색 유도
- API 데이터 없음 → "등록되지 않은 제품" + 성분표 직접 사진 촬영 안내 (v1.1)
- 오프라인 → 캐시된 최근 검색 결과 표시

### 광고
- 분석 결과 화면 하단 배너

## F003. 증상 체크

### 개요
강아지의 현재 증상을 입력하면 심각도를 판단하고 행동 지침을 제공하는 기능

### 입력
- 증상 카테고리 선택 → 세부 증상 선택 → 추가 질문 응답

### 증상 카테고리
```
🤢 소화/구토    — 구토, 설사, 변비, 식욕부진
😮‍💨 호흡       — 기침, 호흡곤란, 코골이 증가
🦵 움직임       — 절뚝거림, 움직임 거부, 떨림
👁️ 눈/귀/코    — 눈곱, 충혈, 귀 긁음, 콧물
🩹 피부/털      — 가려움, 탈모, 발적, 혹
😴 행동 변화    — 무기력, 과한 음수, 배회
🚨 긴급 증상    — 의식 저하, 경련, 호흡 정지
```

### 의사결정 트리 예시
```
구토 선택
  └─ 오늘 몇 번?
      ├─ 1~2번
      │   └─ 혈액/이물질 포함?
      │       ├─ 예 → 🔴 오늘 병원
      │       └─ 아니오 → 🟢 지켜봐도 됨
      └─ 3번 이상 → 🔴 오늘 병원
```

### 출력 — 결과 3단계

| 단계 | 아이콘 | 색상 | 메시지 |
|------|--------|------|--------|
| 즉시 병원 | 🚨 | 레드 | "지금 바로 병원에 가세요" |
| 오늘 병원 | ⚠️ | 옐로우 | "오늘 안에 진료를 받으세요" |
| 지켜봐도 됨 | ✅ | 그린 | "당장 위급하지 않아요" |

**결과 화면 포함 정보**
- 판단 이유 설명
- 집에서 할 수 있는 조치 (지켜봐도 됨 단계)
- 주의 관찰 포인트
- 가까운 동물병원 바로가기 버튼 (즉시/오늘 단계)
- 면책 고지: "이 결과는 참고용이며 수의사 진단을 대체하지 않습니다"

### 광고
- 인터스티셜: 결과 화면 진입 직전 (즉시 병원 단계 제외)
- 결과 화면 하단 배너

## F004. 24시간 동물병원 찾기

### 개요
현재 위치 기반으로 주변 동물병원을 찾고, 24시간 운영 여부를 표시하는 기능

### 입력
- 현재 위치 자동 감지 (expo-location)
- 검색 반경 선택: 500m / 1km / 3km / 5km

### 처리
1. 카카오 로컬 API로 "동물병원" 키워드 검색
2. 운영시간 데이터 파싱 → 현재 운영 중 여부 판단
3. 거리순 정렬

### 출력

**지도 뷰**
- 현재 위치 마커
- 병원 위치 핀
  - 🟢 현재 운영 중
  - 🔴 현재 운영 안 함
  - ⭐ 24시간 운영

**목록 뷰**
각 병원 카드 포함 정보:
- 병원명
- 현재 운영 여부 배지
- 거리
- 전화번호 (탭 시 전화 앱 연결)
- 운영시간

**상세 화면**
- 지도 (해당 병원 위치)
- 전화 버튼
- 길찾기 버튼 (카카오맵/네이버맵 앱 연동)
- 운영시간 전체

### 예외 처리
- 위치 권한 거부 → 주소 직접 입력 유도
- 검색 결과 없음 → 반경 확대 제안
- 오프라인 → 캐시 결과 + 오프라인 안내

### 광고
- 병원 목록 3번째 항목 위치에 네이티브 광고 삽입
- 운영 중인 병원 없을 때 배너 광고

## F005. 건강 기록

### 개요
반려견의 예방접종, 체중, 병원 방문 기록을 로컬에 저장하고 관리하는 기능

### 데이터 저장
- expo-sqlite + Drizzle ORM
- 로컬 저장 (서버 없음)
- 앱 삭제 시 데이터 삭제됨 (v1.0)

### 반려견 프로필
| 항목 | 필수 여부 |
|------|----------|
| 이름 | 필수 |
| 품종 | 선택 |
| 생년월일 | 선택 |
| 성별 | 선택 |
| 중성화 여부 | 선택 |
| 프로필 사진 | 선택 |

### 기록 유형

**예방접종 기록**
| 항목 | 설명 |
|------|------|
| 접종 종류 | DHPPL, 코로나, 켄넬코프, 광견병, 인플루엔자 등 선택 |
| 접종일 | 날짜 선택 |
| 다음 접종 예정일 | 자동 계산 또는 직접 입력 |
| 메모 | 선택 입력 |

**체중 기록**
| 항목 | 설명 |
|------|------|
| 측정일 | 날짜 |
| 체중 | kg 단위 |
| 메모 | 선택 |

체중 변화 그래프 (최근 10개 기록 라인 차트)

**병원 방문 기록**
| 항목 | 설명 |
|------|------|
| 방문일 | 날짜 |
| 병원명 | 텍스트 |
| 방문 이유 | 선택 + 직접 입력 |
| 진단 내용 | 텍스트 |
| 처방약 | 텍스트 |
| 비용 | 선택 입력 |
| 다음 방문 예정일 | 선택 |

### 화면 구성
- 타임라인 뷰: 최신 순으로 모든 기록 표시
- 카테고리 탭: 접종 / 체중 / 병원 분리 조회
- 기록 추가 플로팅 버튼

### 광고
- 기록 탭 하단 배너

## F006. 반려견 프로필 설정

### 개요
앱 최초 실행 시 반려견 정보를 등록하고, 이후 수정 가능

### 온보딩 플로우
```
앱 최초 실행
  → 서비스 소개 (2~3장 슬라이드)
  → 반려견 프로필 등록
  → 홈 화면
```

### 프로필 정보
- 이름 (필수)
- 사진 (선택, 카메라 또는 갤러리)
- 품종 (검색 또는 직접 입력)
- 생년월일 (날짜 피커)
- 성별 + 중성화 여부
